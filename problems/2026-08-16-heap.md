# Problem: Find the K largest elements in an array.

**Category:** Heap  
**Date:** 2026-08-16

## Problem Statement

Find the K largest elements in an array.

## Approach

Min-heap of size K. If new element > heap top, replace top. Final heap contains K largest.

## Complexity

- Time: O(n log n) in the general case
- Space: O(n) auxiliary

## Key Insight

Breaking the problem into smaller subproblems and recognising the pattern
is more valuable than memorising the solution.
