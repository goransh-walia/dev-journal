# Problem: Valid parentheses — check if brackets are balanced.

**Category:** Stack  
**Date:** 2026-08-19

## Problem Statement

Valid parentheses — check if brackets are balanced.

## Approach

Push open brackets onto stack. On close bracket, check if top matches. Empty stack at end = valid.

## Complexity

- Time: O(n log n) in the general case
- Space: O(n) auxiliary

## Key Insight

Breaking the problem into smaller subproblems and recognising the pattern
is more valuable than memorising the solution.
