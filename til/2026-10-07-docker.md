# TIL — Docker (2026-10-07)

## What I learned

`COPY --chown=user:group` in a Dockerfile sets file ownership in one layer instead of a separate RUN chown.

## Why it matters

Understanding this helps write more correct and efficient code.
Small details like this compound over time into significantly better intuitions.
